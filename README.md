# Cubik

A prototype interactive 3D sound sequencer inspired by the 4×4 Rubik’s Cube, exploring new possibilities for sonic interfaces.

Built with Three.js and JavaScript, Cubik transforms a 3D puzzle into a playable musical instrument. Six faces provide independent sound channels, each containing 16 cubelets that define rhythmic patterns. Users can load custom sounds, trigger sequences in real time and manipulate the cube to rearrange compositions.

## Features

- **Interactive 3D interface** — Manipulate the cube in real time.
- **Six sound channels** — One independent channel per face.
- **Grid-based sequencing** — 16 steps per face.
- **Custom sound loading** — Use your own audio samples.
- **Real-time playback** — Trigger and rearrange rhythmic patterns.

## Built With

- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- [Three.js](https://threejs.org/)
- Web Audio API
